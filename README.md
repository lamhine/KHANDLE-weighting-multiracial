# KHANDLE-weighting-multiracial

This repository estimates population-based prevalence of cognitive impairment among Multiracial older adults in California by generalizing results from the KHANDLE cohort to the California BRFSS target population using inverse odds of selection weights (IOSW).

Adapted from the original analysis by Hayes-Larson et al. (2022), this version adds a Multiracial race/ethnicity category and supports two parallel analysis tracks: a replication of the original time period (t10, 2014--2018 BRFSS) and an updated analysis (t16, 2019--2023 BRFSS).

**Original publication:** Hayes-Larson E, Mobley TM, Mungas D, Seamans M, Glymour MM, Gilsanz P, DeCarli C, Whitmer RA, Mayeda ER. Accounting for lack of representation in dementia research: Generalizing KHANDLE study findings on the prevalence of cognitive impairment to the California older population. *Alzheimers Dement.* 2022. doi: 10.1002/alz.12522. [PubMed](https://pubmed.ncbi.nlm.nih.gov/35102726/)

## Repository structure

```
config/
  config.R              # User-specific paths (gitignored; see config_example.R)

R/                      # Shared utility functions (sourced by config.R)
  utils.R               # General helpers (to_num, assert_has_vars, recode_binary01_*)
  race_constants.R      # Race/ethnicity constants and coding helpers
  analysis_helpers.R    # Estimation, MI combination, standardization
  balance_helpers.R     # Covariate balance, weight diagnostics, plotting

01_data-prep/           # Data cleaning (run in order)
  00_pre-cleaning_BRFSS.R        # Read raw BRFSS SAS files, pool years, standardize
  01_clean_BRFSS.R               # Clean BRFSS microdata (recode year-specific variables)
  02_clean_KHANDLE_race.R        # Clean KHANDLE race data (structured + free-text -> MECE)
  03_clean_KHANDLE_othervars.R   # Clean other KHANDLE variables

02_analysis/            # Analysis pipeline (run in order)
  01_multiple_imputation.R       # Multiple imputation (mice) for KHANDLE + BRFSS
  02_harmonization.R             # Harmonize imputed datasets into combined stack
  03_weight_development.R        # Develop IOSW + balance diagnostics
  03a_weight_diagnostics.R       # Optional: diagnose education balance / trimming
  04_iosw_analysis.R             # Estimate naive vs weighted prevalence, PR/PD
  05_g-comp_analysis.R           # G-computation alternative (not used in main results)
  06_results_summary.R           # Generate figures and tables

03_results/             # Output (gitignored; regenerated by pipeline)
  abstract_results.Rmd           # Knittable abstract with inline results + figures
  figures/
  tables/
  supplement/
```

## Setup

1. Clone this repository
2. Copy `config/config.R` and update the Box paths to point to your local KHANDLE/BRFSS data directories
3. Set `analysis_tag` in config to `"t10_replication"` or `"t16_update"`
4. Run scripts in order: `01_data-prep/00_*` through `02_analysis/06_*`
5. Knit `03_results/abstract_results.Rmd` to produce the results summary

## Key design decisions

- **Race classification:** Multiracial = 2+ non-Hispanic race domains; Hispanic overrides all other categories. For t16_update, free-text ethnicity responses are mapped to race domains via a lookup table with manual overrides for ambiguous cases.
- **Weight trimming:** IOSW trimmed at 1st/99th percentiles. KHANDLE over-represents college-educated adults (~50% vs ~16% in BRFSS), requiring aggressive trimming to avoid extreme variance. The overall education gap after trimmed IOSW is modest (~1.3pp).
- **Standard errors:** Within-imputation SEs use a Horvitz-Thompson approximation (appropriate since KHANDLE is a cohort, not a complex survey). Between-imputation variance is captured via Rubin's rules across 20 imputations.
- **Covariate balance (Figure 1):** Computed as true overall SMD (not averaged within-race SMDs) to accurately reflect population-level balance.
